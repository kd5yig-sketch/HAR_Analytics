Inspect every request, see where the time went, and get a list of likely problems: failed requests, server errors, CORS and mixed-content issues, slow DNS/TLS/server responses, redirect chains and more.

The Diagnose tab explains CORS errors, network and certificate failures, which proxy or gateway produced a 5xx, rate limiting and retry storms, errors hidden inside 200 responses, redirect loops, caching and CDN problems, slow page loads, WebSocket issues, hangs and security slips. Drop two HARs to compare them.

The Authentication tab identifies the authentication methods in use (Basic, Bearer/JWT, OAuth/OIDC, SAML, NTLM, Kerberos, API keys, session cookies, signed URLs) and explains why sign-ins and requests were rejected.

How do I capture a HAR file?

Chrome / Edge: open DevTools (F12) → Network tab → tick “Preserve log” → reproduce the problem → click the download arrow (“Export HAR”).
Firefox: DevTools (F12) → Network → reproduce → gear icon → “Save All As HAR”.
Safari: Develop → Show Web Inspector → Network → reproduce → “Export”.
Proxies such as Fiddler, Charles, mitmproxy and Burp can also export HAR.

HAR files can contain passwords, cookies and tokens. Use Export → Redacted HAR before sharing one with anyone.
